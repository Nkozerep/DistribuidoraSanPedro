# Distribuidora San Pedro

Aplicación móvil desarrollada en Android Studio.

## Funcionalidades
- Inicio de sesión con Firebase Authentication
- Obtención de ubicación GPS del dispositivo
- Almacenamiento de coordenadas en Firebase Realtime Database

## Tecnologías utilizadas
- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Google Play Services (GPS)

## Ejecución
El proyecto puede ejecutarse en un dispositivo Android con permisos de ubicación activados.
